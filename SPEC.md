# unified-box3d

Box3D in Odin, made for deterministic rollback. Upstream: https://github.com/erincatto/box3d at
`336263320469e5e9febfe18697ab562488f7e97a` (`UPSTREAM_COMMIT` in `tools/main.odin`). How it was ported, and how to
port an upstream change: `PORTING.md`.

## Layout

- `box3d/`: the port (package `box3d`).
- `export/`: the C API of the shared library (generated by `./b3 gen` from `include/box3d/*.h`).
- `bindings/`: Odin bindings for the library (generated).
- `include/box3d/`: upstream's public headers, verbatim, and `unified.h` (our additions).
- `tests/upstream/` (upstream's tests, ported 1:1), `tests/port/` (ours), `tests/bindings/` (the library through
  the bindings), `tests/compare/` (the C program run against the original and the library), `bench/`.
- `tools/`: the CLI, `./b3` (`b3.cmd` on Windows).

## API

The library exports upstream's C API exactly (`b3CreateWorld`, upstream's struct layouts, C calling convention for
every callback), so the original and this library are interchangeable behind the same headers. Inside the port the
names drop the `b3` prefix (`CreateWorld`, `Body_GetPosition`).

Ours (`include/box3d/unified.h`):
- In-process snapshots, for rollback: `b3World_SaveSnapshot`, `b3World_RestoreSnapshot` (a memcpy of the world's
  arena), `b3DestroyWorldSnapshot`.
- Canonical images, portable across machines: `b3World_SaveImage(world, state, withGeometry)` (self-contained with
  geometry: late join), `b3World_LoadImage`, `b3World_HashState` (the checksum).
- The serializer-based save/restore this started from: `b3CreateWorldStateCache`, `b3World_SaveState`,
  `b3World_RestoreState`, `b3World_RestoreStateFromBytes`.

## Customizations

Every change from upstream is marked `// unified:` in the code (`grep -rn "// unified:" box3d`).

For determinism and the language:
- One SIMD path, 4-wide on `#simd[4]f32` with SSE2's semantics; the AVX2 (8-wide) path and its runtime dispatch are
  not ported, so x64 and arm64 compute the same results. No fused multiply-add.
- Sensor overlaps are sorted with the ported `QSORT` instead of libc `qsort` (whose order of equal keys, and so
  which duplicate is kept, depends on the platform's libc).
- Verstable hash maps are Odin maps (lookup only, never iterated) or small chained maps keyed by content hashes.
- Length-scaled constants (`HUGE`, `LINEAR_SLOP`, ...) are package variables recomputed by
  `SetLengthUnitsPerMeter`.
- `B3_DEBUG` and validation default off (`-define:BOX3D_DEBUG=true`), as upstream's release build (`NDEBUG`).
- Not ported: the Tracy macros, double precision, C++ operator overloads, `#if 0` blocks.
- libc replaced: `core:os` file I/O, `core:time`/`core:thread`/`core:sync` for timers, threads and atomics,
  `remainderf` and `floorf` written out exactly.

For rollback:
- **The world arena** (`world_arena.odin`; `Alloc` in `core.odin`). Everything a world keeps between steps comes
  from its arena: one slot per world in an address range reserved once, never moving. Inside a world's scope
  `Alloc` uses it: the world lookups push it until the end of the caller's scope (`@(deferred_out)`), and the
  built-in scheduler's threads push it while they run the world's tasks. `Free` routes by address, and a growing
  block stays where it lives (`AllocNear`, `PushArenaNear`). The allocator is deterministic (segregated free lists
  that split, then a bump pointer), and its state lives in the arena. Host memory (`AllocHost`) holds the scratch
  stack, per-worker contexts, the scheduler, recordings, the replay player, the name cache, image buffers, and
  user-owned geometry (hulls, meshes, height fields, compounds), whatever scope creates it. The hull database is
  append-only while the world lives, since a rollback may bring back a shape that uses a hull.
- **Snapshots** copy the World struct and every live arena block (freed payloads left out); a restore keeps the
  host-side fields as they are.
- Manifold blocks are 32 elements (upstream 256), so a small world's snapshot doesn't carry empty ones.
- **Canonical images** (`world_image.odin`): every struct the serializer writes goes through a byte mask built once
  from type info (padding, `padding*` fields, pointers, embedded arrays and inactive union members zeroed: the shape
  geometry union whole, the contact union by `simMeshContact`, the joint sim union by type), fused into the copy.
- **Images carry their geometry:** `SerializeWorld(..., img)` writes a table after the header (flags
  `GEOMETRY_TABLE`, `GEOMETRY_BYTES`: per blob kind, byte count, content hash, optionally the bytes), and shapes
  name geometry by table index. `DeserializeIntoShell` resolves the table against the world's geometry store (host
  memory, append-only, verifying carried blobs) before it touches the world. Recording keyframes keep the registry.
- Motion locks also zero the locked velocity components when the step ends (`FinalizeBodiesTask`), after the relax
  iterations and restitution, so locked bodies report clean velocities.

## Proof

- Upstream's 28 test files pass (`tests/upstream`; their determinism hashes, recorded from the C build, match).
- `tests/port`: 1, 2, 4 and 8 workers step bit-identically (bodies, events, the world hash); images are
  byte-identical whatever fresh memory held; a late joiner with geometry made after tick 0 runs on identically.
- `./b3 compare`: the same C program against the original and the library, bit-identical traces.
- Performance (Windows x64, 1000 boxes, `bench/scale.odin`): step as the C library's (~315 vs ~335 µs on one
  worker); snapshot save ~55 µs and restore ~60 µs (the C serializer: 102 and 178); an 8-tick rollback
  3.1–3.7 ms on one worker, 2.0–2.6 ms on four (the C library: 4.0 and 3.4).

## Open

- Snapshots carry array capacity slack: 1.70 MB at 1000 boxes against a 1.34 MB image.
- A task system other than the built-in scheduler would need its tasks run inside the world's arena.
- Upstream quirks seen while porting, kept as they are: `Body_SetType` can return with the world locked;
  `GetWheelJointForce` adds `lowerSuspensionLimit` where an impulse is likely meant; `World_Draw` skips contacts.
